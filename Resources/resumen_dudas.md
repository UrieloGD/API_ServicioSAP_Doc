# Resumen de Dudas y Análisis Arquitectónico (GAP Crítico)

Este documento desglosa cada controlador y método pendiente de migrar de la DMZ, analizando la base de datos a la que se conectaba en `LAN` (SQLServer, SQLite, o AndroidDB), detallando **la consulta completa o SP exacto** que ejecuta para entender qué valida y qué valores retorna. Finalmente, se formulan las **dudas técnicas** que deben resolverse para construir el equivalente en `ServicioSAP`.

---

## 💳 1. Módulo de Crédito (`CreditController`)

| Método DMZ                                                   | BD Actual en LAN      | Acción en LAN (Consulta / Validación / Retorno)                                                                                                                                                                                 | Solucion                                                                                                                           |
| :----------------------------------------------------------- | :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------- |
| `credit/getSms` / `validateSms`                              | MAVICBOSANDROID       | Ejecuta `INSERT INTO TcAAEA00030_EnvioMensajes` con parámetros `@IdRegistro, @IdMensaje, @Cliente, @Telefono`. Retorna `{ "result": recordsAffected }`.                                                                         | insertar en servicioandroid devmavi                                                                                                |
| `credit/codigoPromocion`                                     | SQLServer (Intelisis) | Ejecuta el SP `SpVTASVentaCupon @opcion, @Codigo, @IdEcommerce`. Retorna las filas resultantes de la validación del cupón cargadas en un `DataTable`.                                                                           | usar succes factor para personal para tablas std leer aws de configuraciones y sigmavi para cupones d edevmavi                     |
| `credit/codigoRecomendado`                                   | SQLServer (Intelisis) | Ejecuta `SELECT TOP 1 CONCAT(c.PersonalNombres,' ', c.PersonalApellidoPaterno) FROM CREDIDCodigoRecomendador cr JOIN Cte c on c.Cliente = cr.Cliente WHERE cr.Codigo = @codRecom`. Retorna el nombre completo del recomendador. | leer sigmavi de devmavi                                                                                                            |
| `credit/MonederoSaldoCredito` <br> `GetUnificationWallet...` | SQLServer (Intelisis) | Primero consulta `SELECT SerieMonedero FROM Cte WHERE Cliente = @client`, y luego ejecuta la función escalar `SELECT dbo.FnVTASCalcularSaldo(@resultSerie, @uen)`. Retorna el saldo `decimal`.                                  | sd18 par consultar monedero, para sacar saldo sumar con las nuevas reglas para SAP de organizacion, canal de distribucion y sector |
| `credit/ExistRFCAndPhoneCte`                                 | SQLServer (Intelisis) | Ejecuta `SELECT ISNULL(RFC,'') as RFC, ISNULL(Telefonos,'') as Telefono FROM Cte WITH(NOLOCK) WHERE Cliente = @ClientIntelisis`. Compara los strings y retorna validación (Ej. `ValidationTypeError`).                          | usar BP05  para consultar,                                                                                                         |
| `credit/getPlazos`                                           | SQLServer (Intelisis) | Ejecuta una consulta sobre la tabla de `Condicion` de pago para recuperar el catálogo dinámico (quincenas, enganches). Retorna lista JSON de opciones.                                                                          | SD40 para leer las condiciones de venta                                                                                            |
